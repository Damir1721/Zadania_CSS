Zadanie 22: Użycie ID i zewnętrznego arkusza styli

Shvydkov. Dzisiaj na lekcji informatyki uczymy się podłączać zewnętrzne arkusze stylów CSS. To pozwala na zachowanie porządku w kodzie i ułatwia zarządzanie wyglądem całej witryny. Każdy akapit w tym zadaniu musi zawierać inne teksty powiązane z technologią komputerową.

Shvydkov. Identyfikatory w języku HTML i CSS służą do nadawania unikalnego stylu jednemu elementowi. W arkuszu stylów CSS selektor ID zawsze poprzedzamy znakiem specjalnym hash (kratka). Użycie tego samego identyfikatora więcej niż raz na jednej podstronie jest błędem składniowym.

Shvydkov. Nagłówek poziomu pierwszego wykorzystuje teraz uniwersalny identyfikator. Dzięki temu nie dziedziczy standardowych stylów dla nagłówków, lecz przyjmuje parametry z CSS. Tekst stał się mniejszy, żółty i zmienił krój pisma na popularny Arial.

Shvydkov. Element blokowy DIV również został sformatowany za pomocą tego samego uniwersalnego ID. To pokazuje, że identyfikatory bez przypisanego konkretnego znacznika w CSS (czyli bez "p#" na początku) mogą być z powodzeniem stosowane do zupełnie różnych typów znaczników strukturalnych na stronie.
