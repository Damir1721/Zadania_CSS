Zadanie 21: Tabela pojęć związanych z ID

Pojęcie Znaczenie pojęcia uzupełnia uczeń
Co znaczy skrót ID? ID to skrót od słowa „Identyfikator”.
Jaki jest cel stosowania ID? Cel to zróżnicowanie podobnych elementów na stronie i przypisanie unikalnego formatowania wybranemu obiektowi.
Jakie jest znaczenie znaku # Znak # poprzedza nazwę identyfikatora w arkuszu stylów CSS, informując przeglądarkę, że styl dotyczy selektora ID.
Jak następuje wywołanie ID (wraz z wytłumaczeniem)? Wywołanie następuje za pomocą zapisu id="nazwa_identyfikatora" wewnątrz znacznika HTML. Oznacza to powiązanie elementu HTML ze zdefiniowanym dla niego stylem w CSS.
Uwagi na temat stosowania ID (trzy konieczne wyliczenia).
  1. Identyfikator może wystąpić tylko jeden jedyny raz w całym dokumencie HTML.
  2. Używanie tego samego ID wielokrotnie na jednej stronie jest błędem składniowym (działanie takie jest błędem).
  3. Elementy oznaczone ID muszą być całkowicie unikatowe. Do wielokrotnego formatowania należy używać klas (class).

Przykład z instrukcji (Użycie ID):

Blok tekstu o kolorze zielonym i czcionce 14pt

Blok tekstu o kolorze zielonym i czcionce 20pt (pochylony przez ID)

Blok tekstu o kolorze zielonym i czcionce 14pt
